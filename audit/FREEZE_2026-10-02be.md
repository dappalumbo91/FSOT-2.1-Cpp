# FREEZE 2026-10-02be

Hashed before the run. Round bd found that the step-44 gap opens because one Pauli-Villars eigenvalue, K = 0 and parity +1, changes sign under the mix 0.2. This round asks whether refusing any step that changes the sign of a matched level, and shortening the step when it would, can bring the gap under the existing tolerance 1e-3. It does not change the profile equation and it does not rescore the 91.

## BE-1

Start from the same DPP and the same basis as FREEZE_2026-10-02az: K 14, D 14, kmax 12, nq 1500, Nc 3, mix 0.2, tol 1e-3. The force target is the same edge-tailed balance used by self_consistent_m, including the chiral-limit meson constant. Do not edit tools/cqsm_rot.py.

At each step, match levels inside each (K, parity) sector of each spectrum by the absolute overlap of the eigenvectors, greedy from the largest overlap. A step changes a sign when a matched pair has a different np.sign on the two profiles, or when that overlap is below 1/2, or when the sector dimensions differ. np.sign(0) counts as its own sign, so landing on zero is a change.

The trial mixes are 0.2 times 2^(-k) for k = 0, 1, ..., 8. The floor is 0.2/256. Accept the largest trial that changes no sign. Stop when the gap on the current profile is below 1e-3, or when the floor still changes a sign, or after 80 accepted steps. If the gap is already below 1e-3, record whether the full replacement by the force target would change a sign, and do not apply that replacement when it would.

The step-0 gap must reproduce 0.17211904981809267 within 1e-9. Record the stop reason, the gap, the mix, the valence, the smallest absolute eigenvalue of each spectrum, and the sign-changing matches at the stopping trial. If more than 8 matches change sign, record the 8 with smallest absolute incoming energy and the count.
